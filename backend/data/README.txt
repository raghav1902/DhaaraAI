# 📜 DhaaraAI Real Statutory Datasets Directory
================================================

This directory houses the primary and secondary legal intelligence datasets utilized by DhaaraAI:

1. `sections.csv`: 77,074 statutory provisions indexed across Central Acts from IndiaCode.
2. `mapping.csv`: 2,018 verified concordance mappings connecting legacy acts (IPC, CrPC, IEA) to the new statutory framework (BNS 2023, BNSS 2023, BSA 2023).
3. `acts.csv`: 2,248 indexed Central Acts with ministries, enact dates, and jurisdictions.
4. `comprehensive_statutes.json`: Curated high-frequency provisions covering BNS Sections 318(4), 303, 308, 106, 281, BNSS 173/35, and special acts (Negotiable Instruments Act Sec 138, IT Act Sec 66C/D).
5. `chat_history/`: Local persistent session storage for conversations.

Any additional statutory acts or PDF documents placed in this directory will be indexed automatically by the Dhaara RAG engine.
